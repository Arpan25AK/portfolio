## ✨ Features

* **🚀 Lightning Fast:** Built on **Vite + React**, ensuring rapid Hot Module Replacement (HMR) during development and highly optimized static builds for production.
* **🎨 Modern Aesthetic:** Custom CSS architecture utilizing Glassmorphism, deep dark-mode UI (`#24262B` to `#32353C` gradients), and fluid typography.
* **✨ Advanced UI Components:** Features dynamic isometric 3D social contact cards and smooth hover-state animations.
* **🌧️ Immersive Background:** Includes a custom-built, lightweight Matrix-style digital rain animation using randomized CSS delays.
* **🛣️ Client-Side Routing:** Utilizes `react-router-dom` for instant, page-refresh-free navigation between the home, experience, and deep-dive project pages.
* **🔄 Continuous Deployment:** Integrated with Netlify via GitHub webhooks for automated zero-downtime deployments on every push to the `main` branch.

This portfolio acts as the gateway to my core backend and systems architecture projects:

## 🛠️ Getting Started (Local Development)

To run this portfolio locally on your machine:

**1. Clone the repository**
```bash
git clone [https://github.com/Arpan25AK/portfolio.git](https://github.com/Arpan25AK/portfolio.git)
cd portfolio
2. Install dependencies

Bash
npm install
3. Start the Vite development server

Bash
npm run dev
4. Build for production

Bash
npm run build
